# Ojolade Victor Oladamilare: Student Portfolio

A five-page portfolio website built with plain HTML, CSS and JavaScript. There is no build step and no backend.

## Pages
- `index.html`: Home
- `about.html`: About me
- `projects.html`: Projects and services
- `planner.html`: Academic planner (add, complete, delete and filter tasks; saved in the browser)
- `contact.html`: Contact form with JavaScript validation (name, email, digits-only phone, message)

## Folders
- `css/style.css`: all styles, including the phone layout
- `js/`: `main.js` (menu, footer year, audio fallback), `planner.js`, `contact.js`
- `images/`: photos and icons
- `media/`: put the audio file here (see below)

## Add the audio
Record or create a 10-second audio about solar energy and save it as `solar-energy.mp3` in the `media` folder. The home page already points to that file name. Until the file is added, the page hides the player and shows the words instead.

Script (about 10 seconds):
"Hi, I'm Victor. The sun gives us free energy every day. With solar panels and batteries, your lights stay on even when the grid goes off."

## Preview
Open the folder in VS Code, right-click `index.html` and choose Open with Live Server.
